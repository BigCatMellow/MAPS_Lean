# Context Hygiene

Project memory is a small set of durable facts, not an archive of every chat.

Keep:

- current goal and next action;
- active constraints and unresolved risks;
- decisions and their rationale;
- links to evidence, task records, and handoffs.

Drop or summarize:

- completed task narration;
- raw command output once its result is recorded;
- superseded instructions and corrected examples;
- exploratory discussion that did not affect a decision.

When context is handed off, a new agent should be able to act from the task,
current state, and handoff without reading old transcripts.
