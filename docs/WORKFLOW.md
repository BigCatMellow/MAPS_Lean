# Lean Workflow

## Default path

```
intent → scoped task → one owner → evidence → proportional review → done
```

Use this path for work that matters. A one-file, reversible, low-risk edit may
skip the task file, but not clear scope or verification.

## Task quality

A useful task says:

- what outcome is wanted;
- which paths may change;
- what must not change;
- who owns it;
- how success can be observed; and
- its risk tier.

Avoid assigning two agents overlapping output paths. Split by module, artifact,
or phase; then name the integration owner.

## Native agents

Codex and Claude may spawn their own agents in their native interfaces. Use
parallelism only when the subtasks are independent and the final integrator is
clear. No terminal application is required for visibility or authority.

## Durable continuation

Use a handoff only when someone else must continue or review the work. Keep
[state/CURRENT.md](../state/CURRENT.md) to the current goal, active task links, key decisions,
blockers, and next action. Remove resolved narrative rather than continually
appending to it.
