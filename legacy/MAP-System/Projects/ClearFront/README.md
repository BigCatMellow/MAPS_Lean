# ClearFront

A browser-based trading card game prototype ("simple cards, complex
situations"). Two Champion-led decks, 20 life, 3-card hand, 2-card turn
limit, six factions.

The original prototype is a single self-extracting 4.16 MB HTML bundle.
This project preserves that original untouched under `source/`, extracts
a reproducible/editable baseline, and works toward a modular
(non-single-file) implementation while following the game's own design
principles and rules.

See:

- `shared/project-brief.md` — objective and completion condition
- `shared/requirements.md` — quality standards
- `source/game-card-combat-effects/clearfront_design_principles.md` — governing design rules
- `source/game-card-combat-effects/clearfront_rules.md` — current playtest ruleset
- `risks/RISK_REGISTER.md` — known risks
- `MAP_System/NEW_PROJECT_WIZARD.md` — the bootstrap process this project followed
