## Pieces being combined

### Piece A

- a: The practice lifecycle audit found that MAP's durable sources, task
  ownership, review, and release gates support recovery, but startup contracts,
  intake-to-task continuity, resume pointers, and risk-tier release paths
  disagree at transition seams.

### Piece B

- b: The token audit measured a 1,319-byte scoped operational orientation that
  retained the tested routing action and safety boundary, compared with
  41,485 bytes of raw provenance discovery; it also proved that the current
  67,884-byte mandatory startup stack has not yet been reduced.

### Piece C (optional)

- c: The operating-model comparison favors small, reversible, measured
  improvements and temporary facilitation, while the philosophical discovery
  pass rejects continuous model scouting without a decision trigger and
  useful-yield accountability.

## New combination


- combo: A goal-first, evidence-budgeted practice loop makes MAP coordination cost testable instead of assumed.

## What this makes possible


- opens: One shared definition of success: an operator-guided project reaches a useful reviewed result and recovers correctly after interruption with less interpretation and context cost.

## Why this was not obvious before

- why-hidden: The evidence used to live in separate process audits, local
  retrieval measurements, business-model research, and discovery guidance.
  Looking at any one source can suggest adding a better index, helper, or
  gate; the combination shows that each is only a means toward a recoverable,
  low-interpretation lifecycle outcome.

## Possible uses

- use: Evaluate proposed MAP changes against one shared practice-project
  outcome: correct orientation, a safe first action, interruption recovery,
  independent review, and release with proportional context and coordination
  cost.
- use: Keep helper use temporary and evidence-triggered; turn a repeated
  deterministic success into a self-service command only after measured value.

## Risks or limits

- risk: A broad “improvement loop” can itself become a standing reporting
  ritual. Each trial needs a bounded scenario, named decision consumer,
  baseline, stop rule, and an explicit negative-result path.
- risk: A compact packet can retain most facts yet still omit the crucial
  read-before-mutate boundary. EXP-0004's stated 89.00% scenario-local
  reduction is therefore revision evidence, not permission to replace the
  canonical startup path.
