## Required outcome
Every worker receives the smallest sufficient, correctly sourced information and reusable procedure; the system does not mistake retrieved text or a Skill for authorization.

## Recursive conditions
- **H05.1 — Classify information by authority and job.** Instruction, task contract, fact, Skill, flow, tool and example stay distinguishable. **Proof:** adversarial retrieved material cannot override accepted `AGENTS.md` or task policy.
- **H05.2 — Skill representation and catalog.** Valid open-format Skill files, stable hash/version, provenance, lifecycle and activating trust gate. **Proof:** stale/changed/executable Skill is refused or re-reviewed rather than silently activated.
- **H05.3 — Progressive context delivery.** Retrieve exact task-relevant repo facts, skill descriptions then full Skill only if used; bound token/result budgets; preserve missing-source/UNKNOWN markers. **Proof:** equal or better task outcome versus loading everything, with less irrelevant context.
- **H05.4 — Skill routing must be measurable and precise.** Compare explicit-first and optional selector approaches on direct, paraphrase, vocabulary-shift, hard-negative, ambiguous and no-skill cases. **Proof:** no unearned promotion based on convenience or cherry-picked examples.
  - **H05.4.1** Confirm the real selector is what the frozen evaluation invokes.
  - **H05.4.2** Track false activations and missed skills separately, not just overall F1.
  - **H05.4.3** Honor existing operator disposition for accepted limitations instead of silently reopening completed gates.
- **H05.5 — Semantic retrieval/query expansion conditional.** Master §6.33 requires a frozen comparison beating explicit-first, with cost and hallucination/permission checks; never on by default from a vocabulary gap alone.
- **H05.6 — Capability Packs conditional.** S7 has no implementation and needs demonstrated repeated bundle need and trustworthy Skill/runtime/environment prerequisites.
- **H05.7 — Freshness and information ownership.** A concise index routes to a single concept owner; examples and old reviews are evidence, not a replacement operating contract. **Proof:** a fresh agent can find the needed file in a small number of hops without conflicting instructions.
