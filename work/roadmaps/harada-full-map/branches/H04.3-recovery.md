## Parent condition
[H04 — Continuity and environment](H04-continuity.md). This is a deeply decomposable condition, not a new recovery state machine.

- **H04.3.1 — Detect and bind incident.** Preserve task ID/revision, run ID, session, owner, accepted policy and source event. If sources are unavailable, keep UNKNOWN and investigate rather than infer.
- **H04.3.2 — Check continuation eligibility.** Derive from canonical task policy and current claim/lease; do not trust the stopped session's previously cached authority.
  - **H04.3.2.1 — Lease and task revision.** Block expired/reassigned/stale claims at enforced lifecycle call site. Existing real-stall `LEASE_EXPIRED` exercise is narrow positive proof, not full coverage.
  - **H04.3.2.2 — Environment evidence.** The E5 compatibility helper is documented as *advisory*: verify that an incompatible replacement **cannot silently resume** in the relevant real path before declaring DONE.
  - **H04.3.2.3 — Worktree identity.** E6 guard detects bound worktree mismatch; verify it is actually composed into the intended dispatch/resume pathways, including unexpected paths.
  - **H04.3.2.4 — Validation and policy.** Distinguish opt-in enforcement from default behavior. Follow [H03.3](H03.3-validation.md) and [H06](H06-security.md).
- **H04.3.3 — Decide retry versus reconcile.** Retry only when effect idempotency and budgets justify it; ambiguous external side effects require investigation not replay.
- **H04.3.4 — Preserve replacement lineage and final proof.** New worker/session cannot launder a failed prior review, invalidated run manifest or unfinished acceptance.
- **H04.3.5 — Fault-injection exit test.** Concurrent lease loss, changed task revision, incompatible environment, changed worktree and unknown remote effect. Inspect actual denials/results and ensure no duplicate side effects.

**Boundary:** these are *success requirements*. They do not assert present fail-closed coverage on every path.
