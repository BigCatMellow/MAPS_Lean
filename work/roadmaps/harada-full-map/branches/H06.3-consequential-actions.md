## Parent
[H06 — Security and authority](H06-security.md). This branch is independently addressable because authorization bugs could invalidate the whole program's reliability proof.

- **H06.3.1 — Enumerate effect classes.** Read, reversible write, irreversible/destructive mutation, remote external side effect, secret access, new executable Skill/tool activation, persistent guidance promotion, session recovery. Resolve gray areas from the actual tool call and task policy, not a guessed label.
- **H06.3.2 — Bind permission to canonical task and current run.** Record identity, scope, target, authorizer and required preconditions; fail closed on withheld authority. Approval is explicit and precise, not generated by a plan.
- **H06.3.3 — Enforce on real call sites.** Unit test guards **and** show the actual path invokes them before effect. The checklist reports `DESTRUCTIVE_EXTERNAL_ACTION` at `HarnessService.stop()`; `BEFORE_EXTERNAL_ACTION` lacks a firing site in the recorded baseline. This is an incomplete coverage warning, not proof every actual tool is unsafe.
- **H06.3.4 — Bind review/decision to subject revision.** Reject stale review, wrong branch/target, a helper impersonating authorizer, or new effect after narrowing task scope.
- **H06.3.5 — Treat resumed execution as a new boundary.** Recheck lease, task, policy, environment and worktree before consequential continuation. See [H04.3](H04.3-recovery.md).
- **H06.3.6 — Preserve observability without leaking secrets.** Audit refusal and effect with redacted evidence and stable ID, not raw credentials or unchecked summaries.
- **H06.3.7 — Prove denied and authorized cases.** Define positive/negative tests for each exercised effect class; show a real denied attempt occurs *before* its effect. Only then describe that operation class as enforced.

**Done:** externally inspectable protection for the in-scope operations without a new authority source. **Not done:** all hooks existing as types, a Markdown assertion, or one protective flag defaulting off without acknowledgment.
