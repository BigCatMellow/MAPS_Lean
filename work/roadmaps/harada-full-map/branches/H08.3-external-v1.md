- **H08.3.3 — Instantiate target-scoped discipline.** Use accepted v1 lightweight file convention and sibling adapter in the **target**; do not mutate MAPS_L's canonical .maps state for a target task. Document manual pieces honestly.

- **H08.3.6 — Capture outcome.** Inspectable target PR/review/merge, exact target state, operator interventions, missing protection, unexpected rework and residual risk.
