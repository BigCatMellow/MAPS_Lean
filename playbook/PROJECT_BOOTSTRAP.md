# Project Bootstrap

Use for a project expected to span sessions, accumulate multiple tasks, or use
more than one agent. Skip it for a throwaway experiment.

## Minimum project brain

1. Write a project brief: intent, success condition, non-goals.
2. State quality standards and constraints.
3. Record assumptions and unanswered research questions.
4. Create a risk register, even if its initial answer is “none known.”
5. State decision paths: what the owner can decide versus what needs operator
   direction.
6. Create locations for tasks, decisions, evidence, and handoffs.
7. Create a place for insights, ideas, experiments, and synthesis.
8. Write the first task only after the above is answerable.

Verify a new agent can answer: what are we making; what does good mean; what
is unknown; what can go wrong; who decides; and where does a useful new idea
go?

Use [the project brief template](../templates/project-brief.md),
[the task template](../templates/task.md), [the decision template](../templates/decision.md),
and [the risk-register template](../templates/risk-register.md) as the initial
kit. Add folders only when the work calls for them.
